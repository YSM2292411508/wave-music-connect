# WaveMusic Connect v0.9.3（Windows x64）

正式版安装包由 GitHub Actions 在 Windows 托管运行器上构建并上传。

## 主要更新

- 本地喜欢支持导出 JSON 备份及去重合并导入；不会删除现有收藏。
- 新增最近播放历史（最多 200 首），可在应用内清空，记录仅保留在本机。
- 播放快捷键：Ctrl+Alt+P 播放/暂停，Ctrl+Alt+←/→ 上一首/下一首（应用窗口聚焦时生效）。
- 记住音量设置，保留 0.9.2 的全宽播放进度条。
- Windows 构建流程支持自动发布安装程序和 SHA-256 校验文件。

## 下载与验证

Windows 10/11 x64：下载本页 `.exe` 安装程序后运行；可用同名 `.sha256` 文件校验安装包。
此安装程序未代码签名，Windows 可能提示「未知发布者」。

**验收范围说明：** 自动化类型检查、Vite 构建和 NSIS 打包已通过。尚未在真实 Windows 桌面和三家音乐平台上完成独立的登录、搜索、歌词、播放验收，请根据个人账号权限与平台规则实际测试。

## 数据与限制

- 本地喜欢、播放历史和账号会话仅存在本机；备份不包含平台账号凭据。
- 本项目为非官方第三方客户端，不绕过会员、DRM、版权、地区或风控限制。
- 当前 CI 为避免 GitHub 官方 Electron Release 偶发 HTTP 504，使用第三方 Electron 发行包镜像下载运行时。正式生产分发前应进一步审核构建来源和代码签名。
